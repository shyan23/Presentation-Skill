# Visual grammar and slide layout cookbook

## Hierarchy
Read from 3 distances: thumbnail (composition), laptop (headline/diagram), back row (crucial labels). First visual fixation should land on the most important message. Use clear foreground/background separation, intentional alignment, and generous negative space. Check a slide in grayscale to ensure meaning does not depend on color alone.

## Grid and spacing
- Use a regular alignment grid: e.g., 12 columns with consistent outer margins and fixed gutters, or a deliberate split grid for editorial spreads.
- Suggested 16:9 starter: 5–7% horizontal margin; 4–6% vertical safe margin; 8/16/24/40/64 px-equivalent spacing tokens scaled to output.
- Snap to underlying baselines; align chart annotation, title, and graphic edges.
- Prefer purposeful asymmetry over mechanically centered content, but keep repeated alignments.
- Avoid edge crowding and arbitrary card paddings.

## 15 reusable layout patterns
1. **Statement:** short headline + one textured visual or enormous typographic cue; strong thesis/open/close.
2. **Evidence hero:** conclusion headline, one dominant plot, small source and precise annotation.
3. **Contrast:** split view, two comparable panels, shared scale, decisive difference highlighted.
4. **Before/after:** same frame and criteria, annotated change, no misleading transformed scales.
5. **Mechanism:** nodes with directed flow, consistent arrow meaning, legend, staged details.
6. **Timeline:** chronological horizontal axis, meaningful date gaps or explicit "not to scale".
7. **Decision matrix:** options × criteria, highlighted trade-off row/column, clear evaluation weight.
8. **Hierarchy/tree:** parent-child relationships; distinguish explanatory tree from merely decorative branches.
9. **Progression:** step-by-step concept with optional cumulative reveal.
10. **Picture annotation:** real screenshot/image plus 2–5 precise callouts.
11. **Metric spotlight:** number + units + baseline + timeframe + source; never isolate number without context.
12. **Quote:** short, checked quotation + attribution + consequence.
13. **Case study:** context, action, outcome, lesson; show authentic artifact.
14. **Gallery/taxonomy:** visual classes arranged by actual organizing logic, not default card count.
15. **Interactive pause:** prompt/question with answer on next slide; includes educational function.

## Typography
- Establish 2–3 levels max for most slides: statement, supporting text, evidence label; captions may be smaller.
- Strong font pairing can be 1 family with weights or a display + utility family; preserve non-Latin coverage.
- Default 16:9 talk deck: title 34–56 pt, body 22–30 pt, data labels 16–22 pt; environment varies. Do not force 24 pt into scientific figures where source legibility and density require a redesign instead.
- Contrast semantically: type size *and* weight *and* whitespace; not all-caps everywhere.

## Images and iconography
- Crop for subject and gaze direction. Leave calm space for text.
- Prefer subject-specific evidence: photo of the actual product, site, lab, or workflow.
- Use icons only to encode a distinguishable category or repeated UI language; don't replace nouns with decoration.
- For any generated image, verify text, instruments, logos, architecture details, and physical plausibility. Disclose conceptual status.

## Motion
Animation should aid reveal and causality. Simple build-in for process steps; no spinning, bouncing, glitching, or fly-ins for gravitas. Ensure the slide remains intelligible if viewed as a static PDF.
