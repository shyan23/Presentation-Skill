# Slide functions: choose the job, then the form

| Function | Question answered | Best object | Avoid |
|---|---|---|---|
| Orient | Where are we going? | simple agenda map, one-sentence thesis | long table of contents |
| Claim | What should I remember? | short large assertion, one visual anchor | paragraph-wall |
| Evidence | Why should I believe it? | labeled chart/photo/source proof | unsourced metric |
| Comparison | Which option is better under which conditions? | common-scale table, dumbbell, side-by-side | mismatched axes |
| Mechanism | How does it work? | input-transform-output flow, labeled loop | meaningless arrows |
| Process | What happens in which order? | stages, swimlanes, guard conditions | list pretending to be process |
| Timeline | When did/will events happen? | dated line, phase transitions, milestones | equally spaced inaccurate dates |
| Taxonomy | What categories exist? | matrix, tree, meaningful grouping | arbitrary cards |
| Spatial | Where and how are parts related? | image/schematic with direct labels | abstract conceptual stock photo |
| Quote | What was said and by whom? | verified pull quote plus context | invented quote |
| Case | What happened in this instance? | actual artifact + before/action/outcome | abstract broad claims |
| Decision | What should we do? | criteria, trade-off, recommendation | generic benefits |
| Demo | Can you show it live? | screenshot or functional prototype; fallback | untested live link |
| Teach | Can audience practice the idea? | question, worked example, delayed answer | answer without practice |
| Recap | What patterns connect results? | synthesis map, 3 genuine learnings | bullet repetition of full deck |
| Action | What happens next? | owner, verb, deadline, ask | generic "Thank you" only |

## Selection rules
- If a slide contains **two independent questions**, split or subordinate one.
- A metric without comparator is not evidence unless absolute threshold is meaningful.
- For a process, arrows must encode direction, not mere decoration.
- For a chart, choose the kind that answers the question fastest, not the coolest looking.
- A sophisticated "visual" can legitimately be a few words set beautifully, but only if those words carry the argument.
