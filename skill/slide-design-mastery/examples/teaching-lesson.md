# Example: classroom explanation of supply and demand

**Audience:** introductory economics. **Style:** `playful-classroom` tempered for projection readability.

1. Prompt: "What happens when more people want the same item?" (visual of one product, no false statistics).
2. Define demand with a price/quantity table (numerical sample explicitly hypothetical).
3. Plot downward sloping demand from that same table, annotate axis meaning.
4. Define supply with hypothetical schedule.
5. Overlay supply and demand, show equilibrium with labeled P* and Q*.
6. Ask a prediction question before shifting demand.
7. Reveal rightward demand shock; fixed supply curve; new equilibrium.
8. Compare equilibrium price/quantity in a two-row table.
9. Test an edge case: supply shock instead, then reveal.
10. Summary: one useful verbal rule + independent short quiz.

Visual treatment: simple native charts, semantic orange/blue with shape labels and arrows, minimal box decoration. Never imply a shift in demand is motion along the same curve.
