# Task prompts for reloading / invoking the skill

## Unslop an existing deck
"Load slide-design-mastery. Audit the attached presentation for story, evidence, visual rhythm and AI slop. Pick an audience-appropriate aesthetic. Fix concrete defects while preserving verified numbers and original meaning. Export editable PPTX plus PDF (if possible). Perform a render-by-render QA and summarize important changes."

## Generate an academic talk
"Load slide-design-mastery, especially academic-technical and data-and-diagrams. Make a 12-slide research presentation from my paper. No fabricated experiment. Show source references and proper labels. Use native editable shapes for architecture and export only after visual QA."

## Intentionally different styles
"Load slide-design-mastery. Develop three distinctly different visual concept directions for the same verified 8-slide narrative. Use swiss-grid, editorial-journal and dark-technical. Contrast mood, type roles, layout grammar, image treatment and chart use without changing conclusions."

## Learn from the presenter
"Load slide-design-mastery and the verified transcript I placed at sources/. Extract directly supported design heuristics with timecodes, then test them on executive, research and classroom slide briefs. Keep direct source claims separate from our inferred rules. Update reference files only after verification."

## Critique only
"Load slide-design-mastery. Do a strict BLOCKER/MAJOR/MINOR design and content critique of this PPTX; do not edit it. Return slide-specific repairs and source checks."
